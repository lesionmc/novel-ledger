先给全景：30 个项目分 7 类，每类解决不同环节。最大盘子是 SillyTavern（33.0k★，互动叙事前端），中文赛道实际头部是 AI_NovelGenerator（6.0k★）——比英文工作台头部（2.7k★）高一倍还多。

② 自主写作 Agent
流水线		6autonovel（1.5k）、show-me-the-story（532）主题进、全书出：大纲→逐章→评审自动跑

最大盘子		6SillyTavern（33.0k）、Soul-of-Waifu（1.3k）和角色对话式叙事：角色卡、世界书、长期记忆

AI-Novel-Writing-Assistant ⭐ 2,752 GitHub ↗

工作台/IDETypeScriptAGPLv3 + 商业双协议中英双语

英文工作台头部，端到端「小说生产引擎」：一行灵感自动开书（方向候选→世界观→角色→卷章计划）、Creative Hub + Agent Runtime（Planner/工具注册表/审批节点/可恢复任务）、整书生产链（生成→AI 评审→修复→角色/伏笔状态回填）、拆书工作台、风格引擎（反 AI 规则）、Qdrant RAG、衍生漫画/短剧工作坊。

show-me-the-story ⭐ 532 GitHub ↗

自主AgentGo单二进制自托管OpenAI 兼容任意 API

单 Go 二进制 + Web UI 的自托管小说生成器：设定（手动或 AI 生成）→ 全书大纲（逐行可编辑）→ 逐章流式生成 → 自动事实核查（失败重写 ≤3 次）→ 人工审核 → 完稿后全书诊断 + diff 修订。内置伏笔状态机（planted→progressing→resolved/abandoned，超期 3 章报警）与「去 AI 味 / 6-Gate 检测 / 钩子节奏」技能系统。

下载二进制运行 → localhost:48090 → 建项目 → 填 API → 配置故事 → 大纲 → 开写；支持自动确认模式无人值守；提示词全部可覆盖（{{.KeyName}}）。

部署最简单（单文件）；上下文配方清晰（设定+大纲+活跃伏笔+叙事记忆 2k–20k+最近 5 章摘要+上章结尾 800 字）；伏笔状态机 + 事实核查重写是最实用的一致性方案；零第三方依赖。

同时仅一个 AI 任务；token 随章节增长（10 章≈9K→100 章≈27K 输入）；界面朴素。

全项目最值得抄的实现细节：上下文注入配方、伏笔账本、每章自动核查重写、技能开关设计、纯文件存储（settings/progress/章稿）。

📱4.1 四条路线对比

路线怎么做成本/周期评价与证据
A. Web 服务 + 响应式 PWA
推荐起步		引擎跑在电脑/家庭服务器，界面做成响应式 Web（手机浏览器直接用，可"添加到主屏幕"像 App）；手机连同一 WiFi 访问，或部署到公网 VPS最低 / 1 周内SillyTavern、KoboldAI、show-me-the-story 全是这个形态——天然双端，数据一处存放天然同步，是 30 个项目的主流答案
B. Tauri 2.0 跨端壳一套 Rust 壳打包 Windows / macOS / Linux + iOS / Android，WebView 加载同一套前端中 / 2–4 周适合要"真 App"上架分发时升级；体积小是相对 Electron 的优势
C. Flutter / RN 原生双端移动优先重写客户端，引擎走 API最高 / 1–2 月体验上限最高；但 long_novel_gpt_mobile（Flutter 移植）仅 1★ 的教训：移植本身不构成产品，先有被需要的功能再说
D. 桌面主写 + 手机轻审阅电脑负责重活（生成/大批量），手机只做审阅、批注、语音灵感、通知；数据用 Syncthing / 坚果云 / 自建同步低 / 数天最贴合真实写作流：重活在家干，碎片时间在手机看稿改稿
✅ 推荐：A 起步 →（需要上架时）升 B。理由：一份引擎零分叉、手机天然同步；show-me-the-story / SillyTavern 证明了这条路线在赛道内的通用性。手机端优先做四件事：碎片审稿批注、通勤语音录灵感、推送通知（章节完成/伏笔超期报警）、发布前预览——不做"在手机上写 10 万字"这种伪需求。

结语

30 个项目看完，结论清晰：「写」的各环节都已有 80 分的零件，但没有一个项目把「共创入口 + 中文一致性 + 去AI味 + 双端」拼成 100 分的整体——拼装本身就是机会。骨架抄 show-me-the-story，编排抄 AI-Novel-Writing-Assistant，中文一致性抄 AI_NovelGenerator，设定规范兼容 SillyTavern，去 AI 味做中文空位，双端走 Web+PWA。六到八周，先 P0 验证配方，再逐层叠加。

🎯 一句话记忆：零件都是现成的，没人负责组装；组装者赢——共创入口、中文去AI味、双端审阅，是 30 个项目留下的三把空椅子。

💡 三个即时可用的玩法：① 现实感细节——都市文主角用某新 App，检索它的真实功能细节再写进情节；② 时代背景校准——写 2026 年职场，拉当月热点话题做背景板；③ 脑洞生成器——热点新闻 ×「如果…会怎样」变体批量产出点子（灵感枯竭解药），并可做成每日自动推送。
⚠️ 边界：真实人物入文注意名誉与隐私（模糊化或虚构化处理）；新闻素材"化用不照搬"既是版权要求也是去 AI 味要求。
