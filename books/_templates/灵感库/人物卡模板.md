# 人物卡模板
> 用法：每个有名字的角色一张卡。主角/反派必须四件套齐全（欲望/缺陷/成长弧/声口）。
> 检验法：随机抽三句对白遮住名字，读得出来是谁说的——合格。

# 人物卡：（姓名）
- 身份：（职业/年龄/位置）
- 层级：主角 / 反派 / 配角 / 龙套
- 欲望：表层想要什么；深层想要什么
- 缺陷：性格短板（会让他吃亏的那种）
- 金手指/体质：（如有——必须有规则和限制，不能无限开挂）
- 声口：语速、句式习惯、语气（例：反问句+播报腔 / 文雅爱用比喻 / 短句市井）
- 口头禅：
- 惧怕：
- 成长弧：从「___」到「___」
- 动机层次：表层 → 深层 → 隐藏
- 关键关系：（与其他角色的关系，一条一行）
- 知识边界：（他只知道哪些事——防"谁知道什么"穿帮）

# 反派加答三问
- 他为什么这样做？（答案要让读者能理解，哪怕不认同）
- 他的计划是什么？（每一步都有目的，不为坏而坏）
- 他强在哪？主角凭什么赢？（赢靠成长+代价，不靠主角光环）
