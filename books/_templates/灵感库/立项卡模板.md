# 立项卡模板
> 用法：从上往下填，填不完先空着；但「一句话卖点」必须让自己心跳加速才算过关。
> 填完后把它发给 AI（AI 助手页），说"基于这份立项卡帮我完善设定"。

# 立项卡
- 书名：（可暂定）
- 一句话卖点：___（主角身份）要在___（环境）做___（目标），但___（障碍/反派），如果失败就会___（最坏结果）。
- 题材类型：（平台大类 + 细分标签，例：都市悬疑+刑侦+微灵异）
- 主题立意（≤30字）：
- 故事背景：（时间/地点/社会规则/特殊体系）
- 核心冲突：（一句话说清"谁和谁因为什么对着干"）
- 情节梗概（起/承/转/合，含结局）：
- 叙事视角：（第三人称限知 / 第一人称 / 双线）
- 目标读者/平台：（番茄免费流 / 起点男频女频 / 晋江……）
- 目标篇幅/章均/卷划分：（例：60 万字，章均 2200，3 卷 20+22+18 章）
- 文风约束（3 条具体约束，例：短句为主、冷幽默、对话占比≥40%）：
- 雷点禁区：（你不想写的一切：不开后宫 / 主角不死人 / 不写恋爱……）
- 主要人物：主角___ / 反派___ / 配角___
