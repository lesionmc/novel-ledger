# 01 · 立项说明（novel-ledger · 中文 AI 小说共创写作台）

> 本文档为项目复盘补写，事实依据见 README/代码/记忆日志（2026-09-03 工作日志）。未落实的人名、日期、量化数字一律标注 `[待确认]`，不虚构。

## 1. 一句话定位

**帮人把长篇中文小说写完的工具**：AI 一章一章续写，作者全程把关（定大纲 → 审章节 → 拍板发布）。项目代号曾用名 `ai-novel-workbench`，开源名 `novel-ledger`。

---

## 2. 背景与痛点

### 2.1 现状（2026-09-03 调研结论）

| 项 | 现状事实 | 来源 |
|---|---|---|
| 赛道供给 | GitHub 上 30 个开源项目 / 7 大类，多数是**单点工具**（去 AI 味 40k★、互动扮演 33k★、漫剧 15k★），纵向全栈少（中文头部 AI_NovelGenerator 6k★） | 全景调研 HTML（2026-09-03）+ agent 实抓 8 项目 |
| 全阶段覆盖 | 30 个项目中**无一做全 10 阶段**；成熟项目普遍缺"中文去 AI 味 + 原生双端" | 同上 |
| 本团队起点 | 立项前仅完成方案推演与一页纸 PRD，**未动代码** | 记忆日志·立项拍板条目 |
| 写完能力 | 大模型直接续写长篇，实测第 2 章即出现凭空编造前情（"潜入赵立新办公室"） | 记忆日志·P0 配方验证 |

### 2.2 痛点（两个致命病）

| # | 痛点 | 具体症状（实测/代码可查） | 现有工具为什么治不了 |
|---|---|---|---|
| P1 | **失忆崩坏** | 第 1 章埋的伏笔第 20 章忘回收；角色串戏（安晴被叫"老陈"）；时间倒流；道具漂移（徽章从"荆棘眼"写成"鸟形袖扣"） | 通用 chatbot 靠对话窗口记忆，书一长就溢出；多数开源项目只有摘要链，越写越长、上下文膨胀 |
| P2 | **AI 腔** | "微微/轻轻"满天飞、破折号泛滥、"夜色如墨"、雨刷刮水雾反复收尾 | 去 AI 味工具多为通用 humanizer，不管小说文体，也不管跨章意象复用 |
| P3 | **人机分工不清** | 全代写触碰平台合规红线（番茄勾 AI 标识 / 起点下榜 / 晋江限校对级） | 工具默认"一键成文"，把人排除在流程外 |

### 2.3 不做会怎样

| 不做的后果 | 说明 |
|---|---|
| 长篇写不完 | 30 章以上必然崩，作者要自己人肉记伏笔、查时间线，工程量回落到"手写一个 Excel 表" |
| 写完了不能用 | AI 腔重的稿子过不了平台审核/读者盲测，等于白写 |
| 合规风险自担 | 没有"人把关"的证据链（大纲/审稿/确认改写记录），平台追责时无从举证 |

## 4. 价值主张

| 要素 | 内容 |
|---|---|
| **为谁** | 想写完长篇中文小说、但被"失忆"和"AI 腔"卡住的作者 |
| **解决什么** | 长程一致性崩坏（伏笔/时间/计数/物件）与文体 AI 腔 |
| **通过什么** | ① 滚动状态账本（全书唯一 `story_state.md`，7 小节覆盖式重写，上下文恒定）② 去 AI 味双级引擎（L1 本地词表零 token + L2 模型精判 + 安全 apply）③ 一致性审计 `--audit` ④ 人在闸口（定大纲/审章节/确认改写/拍板发布） |
| **达到什么** | 单本连载到数十章不穿帮、文体过平台审核、全程留痕可举证 |
| **差异化** | 零第三方依赖（Python 标准库）、数据不出本机、任何 OpenAI 兼容模型即插即用、账本是人可读可改的 Markdown |

## 7. 关键约束

| # | 约束 | 依据 / 后果 |
|---|---|---|
| C1 | **零第三方依赖**：只用 Python 标准库（urllib、http.server、json、re、argparse） | 立项拍板；代价是 Web 端自写路由、无异步框架 |
| C2 | **OpenAI 兼容协议，不绑厂商**：改 base_url/model 即切任意厂商 | 记忆日志·模型通道锁定；已实测 Agnes，备选智谱/DeepSeek/Qwen |
| C3 | **AI 是笔，人是作者**：改写在应用前必须出报告 + 人工确认；`--apply` 只自动应用 hard 级 | 产品定位 + 平台合规（番茄勾 AI 标识 / 起点下榜 / 晋江限校对级） |
| C4 | **数据不出本机**：书 = 一个文件夹（Markdown + JSON），无数据库、无云端 | 立项拍板"本地一键跑开源" |
| C5 | **密钥不入库**：key 只放本地 `.env`，仓库只给 `.env.example` | 已实测 `.gitignore` 隔离生效 |
| C6 | **输入 token 阈值约束**：`agnes-2.5-flash` 输入超 ~5k tokens 触发 reasoning 失控吞光 `max_tokens` | 全脚本强制 `reasoning_effort=low`；账本更新/审计对正文做首尾各 1400 字截断 |
| C7 | **零成本优先**：能本地算的不烧 token（L1 词表扫描零 token；L2 只喂命中句局部上下文） | deai.py 设计原则 |
| C8 | **最低 Python 版本 3.9+** | 脚本 docstring 声明 `[待确认：未在 3.9 上实测]` |
| C9 | **Windows 为首要运行环境**：控制台 GBK 编码需 `PYTHONUTF8=1`；端口避开沙箱保留段 | 已踩 WinError 10013（bind 8765）、旧控制台打印崩溃 |
