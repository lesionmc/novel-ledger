# 02 · 需求清单（novel-ledger）

> 本文档为项目复盘补写，事实依据见 README/代码/记忆日志（2026-09-03 工作日志）。
> 优先级定义：**P0** = 不做则产品不成立（核心闭环）；**P1** = 做了才好用/能交付；**P2** = 规划中未开工。
> 信息属性：**明确** = 拍板人明确说过；**承诺** = 已对外承诺（README/开源仓库）；**推断** = 从代码与日志反推；**待验证** = 需确认才能定稿。
> 状态：**已实现** = 代码里有且实测跑通；**部分实现** = 有代码但有已知缺口；**未实现** = 无代码。
