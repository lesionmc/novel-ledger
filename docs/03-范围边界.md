## 1. 做（In Scope）

### 1.1 引擎层（`scripts/`）

| # | 范围项 | 边界说明（做到哪一层） |
|---|---|---|
| S1 | 单章连写 | 按五段配方（创作宪章 + 大纲 + 角色卡 + 滚动账本 + 上一章结尾 800 字）生成 3000 字量级正文 |
| S2 | 滚动状态账本 | **全书唯一** `story_state.md`，7 小节固定结构，覆盖式重写；作者可用任意编辑器手改 |
| S3 | 账本一致性 | 冲突必须显式标注 `⚠冲突`、未了结伏笔/状态不删、关键物件外观严禁漂移（靠提示词规则约束，非程序强制） |
| S4 | 去 AI 味 | L1 本地词表（hard/soft 两级 + 标点密度 + 跨章意象）→ L2 模型精判 → `--apply` 只自动改 hard 级并自动备份 |
| S5 | 一致性审计 | 单章只读审计，报告落盘 `chNNN.一致性审计.md`，不自动修正任何文件 |
| S6 | 模型接入 | OpenAI 兼容协议；主通道 + 一组 FALLBACK 备用通道；任意厂商可切（Agnes / 智谱 / DeepSeek / Qwen…） |
| S7 | 回归保障 | `smoke_test.py` 零网络零依赖冒烟（23 断言） |
| S8 | 命令形态 | CLI（argparse），参数见 README「命令手册」 |

### 1.2 Web 工作台（`web/`）

| # | 范围项 | 边界说明 |
|---|---|---|
| S9 | 本地单机服务 | `http.server` 绑 `127.0.0.1`，端口可配（当前 8801），仅供本机一人使用 |
| S10 | 书与章节管理 | 书列表 / 新建书（复制 `sample_book`）/ 三件套读写 / 章节正文读写 |
| S11 | 引擎动作桥接 | 后端子进程调 CLI：`write` / `audit` / `scan` / `polish` / `apply`，同步等待结果 |
| S12 | AI 对话建书 | 多轮对话 → 产出三件套 → 建书 → 自动 `--init-state` |
| S13 | 设置页 | 只开放 6 个白名单键（`AGNES_API_KEY/BASE_URL/MODEL`、`FALLBACK_API_KEY/BASE_URL/MODEL`），改完实时生效 |
| S14 | 流式对话 | `/api/chat` 支持 SSE 逐 token 输出 |

### 1.3 数据与交付

| # | 范围项 | 边界说明 |
|---|---|---|
| S15 | 存储 | 纯文件：Markdown（设定/角色卡/大纲/账本/正文/报告）+ JSON（`AI腔diff.json`）；无数据库 |
| S16 | 开源 | MIT，仓库 `lesionmc/novel-ledger`，main 分支；`.env` 与章节正文不入库 |
| S17 | 示例与模板 | `sample_book` 三件套模板；`books/雾城档案` 作为能力验证示例（设定/大纲/角色卡/账本随仓库公开） |

## 2. 不做（Out of Scope）

> 每条都是**明确划走的边界**，不是"以后再说"。若要做需重新走范围变更。

### 平台端

| # | 不做 | 原因 / 被谁替代 |
|---|---|---|
| O1 | **不做 SaaS 托管版、不做多人在线服务** | 立项拍板"本地一键跑开源，数据不出用户机器"；托管留二期。当前后端单进程 `ThreadingHTTPServer`，无会话/无并发用户概念 |
| O2 | **不做桌面客户端（Electron/Tauri）、不做移动端 App** | 守住零第三方依赖与纯标准库约束；移动端审稿已降级为 P2 且未开工 |
| O3 | **不做 Docker 镜像与一键安装包** | 依赖约束下"复制文件夹 + 装 Python"即可跑；打包会引入构建链 |

### 用户范围

| # | 不做 | 原因 |
|---|---|---|
| O4 | **不做团队协作（多人合写一本书、评论批注、协同编辑）** | 单人单机的文件存储模型，无锁无版本；协同需引入服务端与冲突合并 |
| O5 | **不做账号体系、注册登录、云端同步** | 数据不出本机的约束下无意义；`.env` 是本机的唯一凭据 |
| O6 | **不服务"量产/批量出书"诉求** | 与"AI 是笔、人是作者"红线冲突；平台合规（番茄勾 AI 标识 / 起点下榜 / 晋江限校对级）下量产即风险 |

### 功能深度

| # | 不做 | 原因 |
|---|---|---|
| O7 | **不做自动大纲/自动设定生成（无人参与的全自动开书）** | AI 建书向导仍需人在对话里定方向、改三件套；"人定大纲"是闸口 |
| O8 | **不做向量检索 / RAG 记忆层** | 当前单层滚动账本已能满足 7 章尺度；引入向量即引入依赖或自写索引，与零依赖冲突（已登记为 P2） |
| O9 | **不做风格克隆 / 模仿特定作者文风** | 版权与合规风险；去 AI 味只做"去掉腔调"，不做"模仿谁" |
| O10 | **不做正文自动润色重写（soft 级自动应用）** | 明确的安全原则：soft 级（副词高频、破折号密度、意象复用）只出报告和示范，交作者人工斟酌 |
| O11 | **不做多语言（仅中文）** | 词表、红线、意象统计全部为中文设计 |
| O12 | **不做全文润色/批量 apply 一键跑全书** | `--apply` 按章执行并逐章备份，是刻意的节流（防 AI 改 AI 引入新腔，apply 后必须 re-scan） |

### 权限粒度

| # | 不做 | 原因 |
|---|---|---|
| O13 | **不做用户/角色权限与操作审计日志** | 单机单人；唯一的安全边界是路径白名单（防路径穿越）与 `.env` 白名单键 |
| O14 | **不做细粒度文件权限（章节级读写控制）** | 同一台机器同一人，无第二主体 |

### 数据范围

| # | 不做 | 原因 |
|---|---|---|
| O15 | **不做数据上云、遥测、埋点、崩溃上报** | 数据不出本机；也因此 M8（外部用户数）无数据来源，标 `[待确认]` |
| O16 | **不做章节正文的版本历史 / Git 式回滚** | 唯一的回滚手段是 `--apply` 自动产生的 `chNNN.bak.md`（只备份首次，不覆盖已有 bak） |
| O17 | **不导入外部素材（联网搜资料、导入已有 TXT/EPUB 拆书）** | 属原方案 P2/P3（联网素材 / 导入拆书），本期未开工 |

### 外部对接

| # | 不做 | 原因 |
|---|---|---|
| O18 | **不对接任何小说平台 API（发布/同步/数据回收）** | 平台无开放投稿 API；发布体检（P2）若要读者反馈，只能靠人工导入 |
| O19 | **不对接第三方登录 / OAuth / 支付** | 无账号体系 |
| O20 | **不做插件生态与公开 API 契约承诺** | `web/server.py` 的 API 是内部契约（前端直连），不对外保证兼容；README 未公开 API 文档 |
