## 一、账本数据字典：`story_state.md`

**定位**：一本书的唯一记忆源（记忆中枢）。位置 `books/<书名>/story_state.md`，文件名常量 `STATE_FILE = "story_state.md"`。

**写入者**：模型（`--init-state` 建初始账；每章后 `update_state()` 覆盖式重写）+ 作者（可随时手改）。
**读取者**：`build_context()`（写章时注入为最高优先级依据）、`audit_chapter()`（作为对照基准）、Web「📒 记忆账本」文档页。

**硬约束**（`STATE_UPDATER_PROMPT` 规则 1）：**7 个小节标题一个都不能改、不能增删，只允许在小节内部增删条目**。

| # | 小节标题（精确字符串） | 含义 | 取值/格式约束 | 谁写 | 示例 |
|---|---|---|---|---|---|
| 1 | `## 当前时间` | 故事现在进行到哪一天、哪个时段 | 只进不退；格式为「YYYY-MM-DD + 时段（可选场景/地点）」；跨天要写明到哪一天哪一时段 | 模型（规则 2） | `- 2009-11-20 深夜至凌晨（安晴老家302室→雾城殡仪馆停尸间）` |
| 2 | `## 计数与资源（每章必须核对更新）` | 有硬上限的能力/道具计数 | 形如「对象·资源名：已用 / 上限」+ 括号内说明；**本章未使用的项保持原值，不许清零**；超限必须付出代价并提前铺垫 | 模型（规则 3） | `- 陈默·今日回闪已用次数：1 / 3`；`- 陈默·薄荷糖储备：约1盒存量-2颗` |
| 3 | `## 角色状态（只记"本章结束时"相对旧账的新变化；无变化不写）` | 逐角色的最新状态/认知/立场/位置 | 形如「角色名：变化描述」；无变化的角色**不写**；旧账里未了结的状态必须保留（可追加「→已于第X章更新」），不许删 | 模型（规则 4） | `- 陈默：得知组织自2006年起长期观察他与安晴；认知从"受害者/追查者"重构为"被观察的共犯/工具"。` |
| 4 | `## 关键事件时间线（最近约 10 条，新的在上）` | 已发生事实的顺序索引 | 有序列表，保留最近约 10 条；更早的合并压缩成一条「（更早：……）」放**最底** | 模型（规则 5） | `1. （空）` 为空占位 |
| 5 | `## 伏笔账本（每条：状态[待回收/已回收/失效] · 埋设章节）` | 伏笔的生命周期台账 | 每条必须带状态（`待回收` / `已回收` / `失效`）+ 埋设章节；回收时改成「已回收·回收于本章」；**已登记的条目不许丢** | 模型（规则 6） | `- （空）` 为空占位 |
| 6 | `## 关键物件（外观一经写死严禁漂移）` | 重要道具的**不可变**事实 | 每条含：物件名 + 外观 + 现在归属 + 所在位置；**旧账已登记物件的外观严禁改动**；新物件必须登记 | 模型（规则 7） | `- （空）` 为空占位 |
| 7 | `## 待续状态` | 下一章最该接续的点 | 一句话 | 模型（规则 由模板决定） | `- （下一章最该接续的点，一句话）` |

### 1.1 账本头（模板固定部分）

```
# 《{书名}》· 故事状态账本（机器维护，作者可改）
> 本文件是续写章节时的唯一记忆源。每写完一章，AI 会基于"旧账 + 本章正文"重写全账。
> 作者可随时直接修改本文件，AI 续写时必须遵守。
```

### 1.2 账本内特殊标记

| 标记 | 出现位置 | 含义 | 处置 |
|---|---|---|---|
| `⚠冲突：旧账记X，本章写Y（请作者裁决）` | 任意小节 | 模型发现正文与旧账矛盾（时间倒退、计数不一致、角色状态/位置矛盾、物件归属或外观变化）时**必须**追加，不许悄悄覆盖（规则 9） | 人工裁决：改正文或改账本 |
| `（空）` | 各小节 | 模板空占位 | 正常，随写作被填充 |
| `（更早：……）` | 关键事件时间线最底部 | 被压缩的历史事件 | 只读，勿删 |
| `→已于第X章更新` | 角色状态 | 旧状态被新状态接续 | 保留，作为演变轨迹 |

### 1.3 账本完整性校验清单（人工/脚本均可执行）

| 检查项 | 通过标准 |
|---|---|
| 7 个 `## ` 标题齐全且拼写一致 | 缺任一 = 账本损坏 |
| 末行是完整标题或完整条目 | 出现截断标题（如 `## 关键事件时间线（最近约 10`）= **账本被截断**，必须修复 |
| `## 计数与资源` 没有出现「0 / 3」式的异常清零 | 未使用项应保持原值 |
| `## 关键物件` 每条都有外观描述 | 防漂移 |
| 无 `⚠冲突` 未处理项 | 有则先裁决再续写 |

> 🔴 **当前示例书实测**：`books/雾城档案/story_state.md` 共 19 行 918 字符，末行停在 `## 关键事件时间线（最近约 10`，**第 4–7 节缺失**，校验不通过。属模型输出被截断导致，需人工修复后再续写（见 `09-风险清单.md` R-09）。

### 2.1 书目录下的文件（`books/<书名>/`）

| 文件 | 格式 | 生成者 | 用途 | 是否入库 |
|---|---|---|---|---|
| `设定.md` | Markdown（一级标题 `# 《书名》· 创作宪章与世界观设定` + 世界观 + 硬性写作约束） | 人 / AI 建书向导 | 创作宪章，`build_context()` 第 1 块注入；**关键道具外观必须在此写死** | ✅（`books/` 未被 ignore，仅 `chapters/` 被排除） |
| `角色卡.md` | Markdown（每人一个 `##`，含身份/背景/性格/说话方式/当前状态） | 人 / AI 建书向导 | 活跃角色卡，第 3 块注入 | ✅ |
| `大纲.md` | Markdown（全书主线 + 分卷细纲，含每章目标/事件/钩子） | 人 / AI 建书向导 | 全书大纲，第 2 块注入 | ✅ |
| `story_state.md` | Markdown，7 小节固定结构（见 §一） | 模型（`--init-state` / `update_state`），人可改 | 记忆中枢 | ✅ |
| `chapters/` | 目录 | 引擎首次写章时创建（Web 侧 `PUT /ch/{no}` 会 `makedirs`） | 正文与全部产物 | ❌（`.gitignore` `**/chapters/`） |

### 2.2 章节目录下的文件（`books/<书名>/chapters/`）

识别规则：正文必须匹配 `^ch\d{3}\.md$`（3 位数字）；`chapter_files()` 按 `int(f[2:5])` **数值排序**（避免 `ch010` 排到 `ch002` 前）。

| 文件命名 | 格式 | 生成者（代码位置） | 内容要点 | 是否入库 |
|---|---|---|---|---|
| `chXXX.md` | 纯文本小说正文（无 front-matter） | `write_chapter.py` 写章流程第 3 步；Web `PUT /ch/{no}` 可人工覆盖 | 约 3000 字；`XXX` 为 3 位零填充章号（`ch{no:03d}.md`） | ❌ |
| `chXXX.AI腔体检.md` | Markdown 人读报告 | `deai.polish_chapter()` | ① 头部引用行：`> 引擎：L1 词表硬筛（hard×N / soft高频×N / 破折号×N / 省略号×N）→ L2 AI 精判 N 条。` ② `## 判定为 AI 腔 · N 条（建议改）`（每条 `**idx.** 理由` + `- 建议：改写`） ③ `## 正常表达（保留）· N 条` ④ 可选 `## 跨章意象提示（L1 给出，供作者斟酌）` | ❌ |
| `chXXX.AI腔diff.json` | JSON 数组 | `deai.polish_chapter()`（仅当存在 hard 级 `verdict=ai` 项时写；无则**删除**旧文件） | 元素字段见 §2.3 | ❌ |
| `chXXX.一致性审计.md` | Markdown 审计报告 | `write_chapter.audit_chapter()` | 模型自由输出，实测结构为 `## 审计清单` → `### 冲突` / `### 漏记` / `### 存疑`，每条含 `**问题描述**` 与 `**建议改法**`；无问题时输出「未发现冲突/漏记」 | ❌ |
| `chXXX.bak.md` | 与 `chXXX.md` 同格式 | `deai.apply_chapter()`，**仅当文件不存在时创建** | 首次应用改写前的原稿 | ❌（`.gitignore` `*.bak.md`） |
| `_bak_v1_截尾记忆/` | 目录（人工创建的历史归档） | 人 | 截尾记忆方案时期的旧版本存档 | ❌ |

### 2.3 `chXXX.AI腔diff.json` 字段字典

```json
[
  {
    "idx": 1,
    "line": 3,
    "orig": "夜色沉得像墨。",
    "rewrite": "夜色浓得化不开。",
    "reason": "「夜色如墨」是极高频率的陈词比喻，换成白描式质感描述即可。"
  }
]
```

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `idx` | int | 候选条目序号（与 L2 prompt 中 `[idx]` 对应，1 起） | 必须在 `hard_idx_map` 中才可能进入 diff |
| `line` | int | 原句所在**行号（1 起）** | apply 时校验 `0 < line <= len(lines)`，越界跳过 |
| `orig` | string | 原句完整文本（由 `extract_full_sentence()` 切出，含句末标点，**不含外侧引号**） | apply 时必须为 `lines[line-1]` 的精确子串，否则跳过 |
| `rewrite` | string | 改写后的**完整句**（保留无需改动部分，含句尾标点） | 由模型给出；为空则该项跳过 |
| `reason` | string | 一句话理由 | 可为空字符串 |

**入选条件（代码级）**：`verdict == "ai"` 且 `rewrite` 非空 且 `idx in hard_idx_map` → 即**只有 hard 级**会被自动应用，soft 级永远不进 diff。

## 三、接口定义

### 3.1 CLI · `scripts/write_chapter.py`

调用：`python scripts/write_chapter.py [参数]`
配置生效链：**命令行 > `.env` > 内置默认**；例外：API Key 为 `--key` > 环境变量 `AGNES_API_KEY` > `.env` 的 `AGNES_API_KEY` > 环境变量 `ZHIPU_API_KEY`。
`.env` 读取路径：脚本所在目录的上一级（即项目根）。

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `--book` | str | `""` | 书目录（含 `设定.md`/`角色卡.md`/`大纲.md`）。**必填**；不存在则打印「书目录不存在」并返回 1 |
| `--chapter` | int | `0` | 要写的章节号（1 起）。`<1` 且未指定 `--init-state` 时提示并返回 1 |
| `--key` | str | `""` | API Key，覆盖 `.env` |
| `--base-url` | str | `None` | 覆盖 `AGNES_BASE_URL` |
| `--model` | str | `None` | 覆盖 `AGNES_MODEL` |
| `--reasoning-effort` | str | `"low"` | 思考预算：`low/medium/high/none`；为 `none` 时不发送该字段 |
| `--init-state` | flag | — | 按三件套生成初始 `story_state.md`（写第 1 章前跑一次）；执行后直接 `return 0` |
| `--no-state` | flag | — | 写正文后跳过账本更新（调试用） |
| `--state-only` | flag | — | 只重算账本不重写正文（需 `--chapter N` 指定依据哪一章）；章不存在返回 1 |
| `--audit` | flag | — | 一致性审计（需 `--chapter N`）；只读，不改账本与正文 |

**动作优先级**（`main()` 内的判断顺序）：`--init-state` > `--chapter < 1` 报错 > `--audit` > `--state-only` > 默认写章流程。

| 退出码 | 含义 |
|---|---|
| `0` | 成功 |
| `1` | 缺 key / 书目录不存在 / 未指定 `--chapter` / `--state-only` 找不到正文 |
| `SystemExit`（非 0） | 审计时缺账本或缺正文（`raise SystemExit` 带中文提示） |

### 3.2 CLI · `scripts/deai.py`

调用：`python scripts/deai.py --scan|--polish|--apply …`
**注意：本脚本没有 `--key` 参数**，Key 只能来自环境变量或 `.env` 的 `AGNES_API_KEY`。

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `--scan` | `BOOK_DIR` | — | 全书 L1 体检（本地零 token），控制台输出，**不落盘** |
| `--polish` | `BOOK_DIR` | — | 单章 L2 精判，落盘体检报告 + diff JSON（不改正文） |
| `--apply` | `BOOK_DIR` | — | 按 diff JSON 应用改写（自动备份 `.bak.md`） |
| `--chapter` | int | `None` | 配合 `--polish` / `--apply`，缺则打印「需要 --chapter N」返回 1 |
| `--model` | str | `None` | 覆盖 `AGNES_MODEL` |
| `--base-url` | str | `None` | 覆盖 `AGNES_BASE_URL` |
| `--reasoning-effort` | str | `"low"` | 同 write_chapter |

**动作优先级**：`--scan` > `--polish` > `--apply`；三者都不给则打印 help 返回 1。

**L1 判定口径**（`l1_scan_book()`）：

| 类别 | 判定 | 权重 |
|---|---|---|
| hard 词 | `AI_TONE_BLACKLIST` 中 weight=hard 的词出现在**某行** | 每次命中 +2 |
| hard 正则 | `HARD_PATTERNS`：`夜色…如墨/似墨/像墨/沉得像墨/浓得像墨`、`仿佛…一般|似的`、`空气…凝固/安静得/静得` | 每次命中 +2 |
| soft 词 | `AI_TONE_BLACKLIST` 中 weight=soft 的词**全文出现次数 ≥ 2**（`SOFT_THRESHOLD`） | 每个词 +1 |
| soft 正则 | `SOFT_PATTERNS`：`不是…，而是`，全文出现次数 ≥ 2 | +1 |
| 破折号 | `—{2,}` 或 `——` 计数；每千字 ≥ 2.0（`DASH_PER_1000`） | 超标 +1 |
| 省略号 | `…{2,}` 或 `……` 计数；每千字 ≥ 1.5（`ELLIPSIS_PER_1000`） | 超标 +1 |

`score = hard条数×2 + soft项数 + 破折号超标 + 省略号超标`；`AI 腔指数 = round(score × 1000 / 去空白字数, 1)`（越高越腔）。
跨章意象提示（`IMAGE_WORDS` = 雨刷/雨刮/水雾/雾气/夜色/墨色/霓虹）：**总次数 ≥ 3 且 跨章数 ≥ 2** 才提示。

### 3.3 Web API 全路由表

**通用约定**
- 基址：`http://127.0.0.1:<port>`（`server.py` 模块默认 `--port 8000`；`start-web.bat` 传 `8801`）。
- 所有 `/api/*` 响应 `Content-Type: application/json; charset=utf-8`，成功 `200`（并带 `Cache-Control: no-store`），错误体为 `{"error": "<中文说明>"}`。
- 路由分发：路径按 `/` 分段为 `segs`，`segs[0] == "api"` 进 API 处理，否则当静态文件（`web/static/`）。
- 未匹配路由 → `404 {"error": "no route"}`（或 `"unknown path"`）；处理异常 → `500 {"error": "<异常类型>: <信息>"}`。
- 路径中的书名、文件名需 URL 编码（前端用 `encodeURIComponent`）。
- 无鉴权、无 CSRF、无分页。

| # | 方法 | 路径 | 入参 | 成功返回 | 错误码 |
|---|---|---|---|---|---|
| 1 | GET | `/api/status` | — | `{"ok":true,"key_set":bool,"books_dir":str,"settings":{6键}}` | — |
| 2 | GET | `/api/settings` | — | `{"settings":{白名单6键当前值}}` | — |
| 3 | PUT | `/api/settings` | body `{"changes":{键:值}}` | `{"ok":true,"settings":{完整6键},"key_set":bool}`；只改白名单键，实时生效 | `400`「需要 changes 字段」 |
| 4 | POST | `/api/settings/test` | body JSON（任意） | `{"ok":true,"sample":str,"model":str}`；实际用**服务端现配的 key**发一条 `ping/ping`（`max_tokens=4`）验证连通 | `502`「连接失败：…」 |
| 5 | POST | `/api/chat` | body `{"messages":[…],"temperature"?:num,"stream"?:bool}` | 非流式：`{"ok":true,"content":str}`；流式：SSE（`text/event-stream`），事件 `delta` / `done` / `error` | `400`「messages 不能为空」；`502`「AI 调用失败：…」；流式未配 key → `401` |
| 6 | GET | `/api/books` | — | `{"books":[目录名…]}`（按字典序，排除 `.` 开头与非目录） | — |
| 7 | POST | `/api/books` | `{"name":"新书"}` | 复制 `sample_book/` → `books/<name>`；`{"ok":true,"name":str}` | `400`「书名非法（不能含 / 或 \）」「同名书已存在」 |
| 8 | POST | `/api/book/from-chat` | `{"name":str,"files":{"设定":str,"角色卡":str,"大纲":str}}` | 复制模板 → 覆盖三件套 → 跑 `--init-state`；`{"ok":<引擎返回>,"name":str}` | `400`「书名非法」「files 需要包含 设定/角色卡/大纲 三份」「同名书已存在」；`500`「建书失败：…」 |
| 9 | GET | `/api/book/{book}` | — | `{"name":str,"chapters":[{"no":int,"file":"chXXX.md"}],"next_no":int,"has_state":bool}` | `404`「书不存在: <name>」 |
| 10 | GET | `/api/book/{book}/doc/{doc}` | `doc` ∈ `设定`\|`角色卡`\|`大纲`\|`state`（`state`→`story_state.md`） | `{"doc":str,"content":str}` | `404`「doc 必须是 设定\|角色卡\|大纲\|state」「文件不存在」 |
| 11 | PUT | `/api/book/{book}/doc/{doc}` | body = 文档**原文**（非 JSON，直接写盘） | `{"ok":true}` | `404` 同上；`400` 无 |
| 12 | GET | `/api/book/{book}/ch/{no}` | `no` 为正整数字符串 | `{"no":int,"content":str}` | `400`「章号格式错误」；`404`「该章不存在」 |
| 13 | PUT | `/api/book/{book}/ch/{no}` | body = 正文**原文**；自动 `makedirs(chapters)` | `{"ok":true,"no":int}` | `400`「章号格式错误」 |
| 14 | GET | `/api/book/{book}/files` | — | `{"files":[{"file":"chapters/xxx","size":int}]}`；收录规则：`ch\d+\.(md\|json)` 或 文件名含「体检」或「审计」 | `404` 书不存在 |
| 15 | GET | `/api/book/{book}/file/{rel}` | `rel` 需匹配 `chapters/[^/]+\.(md\|json)` 或恰为 `story_state.md` | `{"file":str,"content":str}` | `403`「只允许读 chapters/ 下的文件或账本」；`404`「文件不存在: <rel>」 |
| 16 | POST | `/api/book/{book}/write` | `{"no"?:int}`（缺省自动取 `next_no`） | `{"ok":bool,"no":int,"chars":int,"body":str,"log":str(尾部2000字符)}`；缺账本时自动先跑 `--init-state` | `404` 书不存在 |
| 17 | POST | `/api/book/{book}/audit` | `{"no":int}` | `{"ok":bool,"no":int,"report":str\|null,"log":str(1500)}` | `400`「需要 no」 |
| 18 | POST | `/api/book/{book}/scan` | `{}` | `{"ok":bool,"report":str}`（引擎 stdout+stderr 全文） | — |
| 19 | POST | `/api/book/{book}/polish` | `{"no":int}` | `{"ok":bool,"no":int,"report":str\|null,"log":str(1500)}` | `400`「需要 no」 |
| 20 | POST | `/api/book/{book}/apply` | `{"no":int}` | `{"ok":bool,"log":str(1500)}` | `400`「需要 no」 |
| 21 | GET | `/` `/index.html` `/static/{file}` | — | 静态文件（`web/static/` 下）；未知扩展名 → `application/octet-stream` | `403` 越界；`404`「not found: <rel>」 |

**子进程序超时**：通用 900s；`scan` 120s；`polish` 300s；`apply` 60s。超时返回 `ok:false` + `log` 为「引擎执行超时（超过 Ns）」。

**SSE 事件格式**（路由 5 的流式分支）：

| 事件 | data 载荷 | 说明 |
|---|---|---|
| `delta` | JSON 字符串（增量文本） | 每个非空 `choices[0].delta.content` 发一次 |
| `done` | `{}` | 上游出现 `data: [DONE]` |
| `error` | JSON 字符串（错误信息） | 读取/解析异常 |

响应头另带 `Cache-Control: no-cache` 与 `X-Accel-Buffering: no`（防中间层缓冲）。
