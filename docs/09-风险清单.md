# 09 · 风险清单

本文档为项目复盘补写，技术事实以代码为准（依据：源码核对 + 示例书 `books/雾城档案` 实测状态）。

**等级口径**

| 等级 | 含义 | 处置时限 |
|---|---|---|
| 🔴 高 | 会导致数据丢失、功能不可用或安全事故 | 立刻处理 / 下次使用前必须处理 |
| 🟡 中 | 会造成体验损失或隐性错误，可绕过 | 本迭代内排期 |
| 🟢 低 | 已知小瑕疵、有明确绕法 | 记录观察，择机处理 |

**责任人口径**：本项目为单人 + AI 协作，责任人统一为「作者（本人）」与「AI 助手」两类；拆分方式见 `14-完成定义与协作机制.md` 的 RACI。
