本文档为项目复盘补写，技术事实以代码为准（依据：`scripts/*.py`、`web/server.py`、`start-web.bat`、`.env.example`）。

## 一、快速开始（约 5 分钟跑通）

### 1.1 三步准备

| 步骤 | Windows（CMD / PowerShell） | macOS / Linux（Terminal） |
|---|---|---|
| ① 准备配置 | `copy .env.example .env` | `cp .env.example .env` |
| ② 填 Key | 用记事本/VS Code 打开 `.env`，把 `AGNES_API_KEY=sk-你的key` 换成真实 Key | 同左 |
| ③ 建书 | `xcopy /E /I sample_book books\我的书` 或直接复制文件夹 | `cp -r sample_book books/我的书` |
| ④ 改设定 | 编辑 `books/我的书/` 下的 `设定.md`、`角色卡.md`、`大纲.md` | 同左 |
| ⑤ 初始化账本 | `python scripts\write_chapter.py --book books\我的书 --init-state` | `python3 scripts/write_chapter.py --book books/我的书 --init-state` |
| ⑥ 写第 1 章 | `python scripts\write_chapter.py --book books\我的书 --chapter 1` | `python3 scripts/write_chapter.py --book books/我的书 --chapter 1` |

> **Windows 中文乱码先手**：若第 ⑤⑥ 步报 `UnicodeEncodeError`，先执行 `set PYTHONUTF8=1`（PowerShell：`$env:PYTHONUTF8=1`），再跑同一条命令。

### 1.2 之后每章一条命令

```bash
# 第 2 章、第 3 章……一路连写
python scripts/write_chapter.py --book books/我的书 --chapter 2
python scripts/write_chapter.py --book books/我的书 --chapter 3
```

**写章时终端会看到什么**

```
[1/4] 组装上下文配方（第 2 章）...
[2/4] 调用 agnes-2.5-flash 生成正文...
[用量] 输入 3210 / 输出 2987 / 总 6197 tokens | finish=stop
[3/4] 正文已落盘 → …/chapters/ch002.md（2987 字）
     更新滚动账本（记忆回填）...
     账本已更新 → …/story_state.md
提示：下一章用 --chapter 3 续写，会自动带滚动账本记忆验证不崩。
```

看到 `finish=stop` 就是正常完成；若看到 `finish=length`，说明输出被截断（正文可能不完整），需重跑。

### 1.3 三条可选流程

| 目的 | 命令 | 耗时 | 花 token 吗 |
|---|---|---|---|
| 全书 AI 腔体检 | `python scripts/deai.py --scan books/我的书` | 秒级 | **不花**（本地正则） |
| 单章 AI 精判 | `python scripts/deai.py --polish books/我的书 --chapter 2` | 十秒级 | 花 |
| 应用改写 | `python scripts/deai.py --apply books/我的书 --chapter 2` | 亚秒级 | 不花 |
| 一致性审计 | `python scripts/write_chapter.py --book books/我的书 --audit --chapter 2` | 约 1 分钟 | 花 |
| 回归测试（改代码后） | `python scripts/smoke_test.py` | 秒级 | 不花（零网络） |

## 二、Web 工作台使用

### 2.1 启动

| 系统 | 方式 |
|---|---|
| Windows | **双击 `start-web.bat`**，浏览器打开 `http://127.0.0.1:8801` |
| macOS / Linux | 终端执行 `python3 web/server.py --port 8801`，浏览器打开 `http://127.0.0.1:8801` |

启动成功后黑窗口会显示：

```
novel-ledger Web 工作台已启动
  浏览器打开 → http://127.0.0.1:8801
  书目录 → …\books
  API key: 已配置 ✅    ← 若显示「未配置 ⚠ 写章会失败，请先配 .env」，先去 ⚙ 设置里填
```

> ⚠ 已知事项（2026-09-04 更新）：① ~~端口不一致~~ **已修复**（bat 提示与实际端口统一为 8801，2026-09-03）；② bat 里写死了 Python 绝对路径，换机器需手改（见 `09-风险清单.md` R-18）。

**停止服务**：在黑窗口按 `Ctrl+C`（不要直接关窗口，残留进程会占住端口）。

### 2.2 三个视图能干什么

| 视图 | 怎么进 | 有什么 | 能做什么 |
|---|---|---|---|
| **首页 hero** | 启动即到 / 点左上角 🏠 | 三张卡片（AI 聊天建书 / 复制模板建书 / 去 GitHub）+ 已建书列表 | 选一本书进入、新建书、看每本已有多少章、账本是否就绪 |
| **书内（三栏）** | 点书树里的书名 | 左栏：我的书 / 章节 / 报告产物；中栏：正文或文档编辑器；右上：操作按钮 | 见 §2.3 |
| **AI 建书向导** | 首页「✨ 和 AI 聊天创建新书」或右上角「+ 新建书」 | 左：聊天区；右：三件套预览与编辑 | 三步建书，见 §2.5 |

### 2.3 书内视图逐块说明

**左栏**

| 区块 | 内容 | 点击效果 |
|---|---|---|
| 📚 我的书 | 所有 `books/` 下的目录 | 切换书 |
| 📑 章节（N 章） | `ch001.md ch002.md …` + 体积（如 13.6K） | 打开该章正文到编辑器 |
| 🧾 报告/产物 | 体检报告、审计报告 | 只读打开（Markdown 渲染；`.json` 以等宽文本展示） |
| ⟳ 刷新 | — | 重新拉取书列表与文件树 |

**中栏（编辑器）**

| 打开的对象 | 标题栏示例 | 右下角折叠面板 | 顶部按钮 |
|---|---|---|---|
| 章节正文 | `📚 雾城档案 · ch005.md · 15604 字` | 💬 AI 助手（带当前正文前 4000 字作为上下文） | ✍ 写下一章 / 🔬 全书体检 / 一致性审计 / 去味精判 / 应用改写 / 💾 保存 |
| 设定 / 角色卡 / 大纲 | `📚 雾城档案 · 📄 设定.md · 1738 字` | 💬 AI 助手（针对该文档提问） | ✍ 写下一章 / 🔬 全书体检 / 💾 保存 |
| 记忆账本（state） | `📚 雾城档案 · 📒 记忆账本 · 918 字` | 💬 AI 助手 | 📒 刷新 / 🔬 全书体检 / 💾 保存 |

- **编辑即改文件**：`Ctrl+S`（或点 💾）保存，直接写回 `chXXX.md` / `设定.md` / `story_state.md`。
- **切换前会静默保存**：点任何动作按钮时都会先 `saveCurrent(true)`，不用担心丢失。
- **右下状态条**：左边圆点（● 绿=已连接 / ● 红=出错 / ○ 灰=空闲）+ 当前动作 + 最近日志片段。

**主要动作按钮一览**

| 按钮 | 背后发生什么 | 耗时 | 副作用 |
|---|---|---|---|
| ✍ 写下一章 | `write_chapter.py --chapter <next_no>`；缺账本会先自动 init | 1–3 分钟 | 新增 `chXXX.md` + 覆盖更新账本 |
| 一致性审计 | `write_chapter.py --audit --chapter N` | 约 1 分钟 | 只新增 `chXXX.一致性审计.md`，**不改任何文件** |
| 🔬 全书体检 | `deai.py --scan` | 秒级 | 只显示报告，不落盘、不花 token |
| 去味精判 | `deai.py --polish --chapter N` | 十秒级 | 生成 `chXXX.AI腔体检.md` + `chXXX.AI腔diff.json`，**不改正文** |
| 应用改写 | `deai.py --apply --chapter N`（**弹窗二次确认**） | 亚秒级 | **改正文**；首次会自动备份 `.bak.md` |
| 📒 刷新（账本页） | 重新读取 `story_state.md` | 即时 | 无 |
| 💾 保存 | 写回当前编辑内容 | 即时 | 覆盖文件（无自动备份，注意） |

### 2.4 ⚙ 设置页怎么配

点右上角 ⚙ → 弹窗内两组共 6 项：

| 分组 | 字段 | 对应 `.env` 键 | 说明 |
|---|---|---|---|
| 主模型 | API Key | `AGNES_API_KEY` | 换厂商也填这里 |
| | Base URL | `AGNES_BASE_URL` | 例：`https://apihub.agnes-ai.com/v1/`（Agnes）、`https://open.bigmodel.cn/api/paas/v4/`（智谱）、`https://api.deepseek.com/v1/`（DeepSeek） |
| | Model ID | `AGNES_MODEL` | 例：`agnes-2.5-flash`、`glm-4.5-flash`、`deepseek-chat` |
| 备用模型 | Fallback API Key / Base URL / Model ID | `FALLBACK_*` | **主模型连续失败才切换**；`FALLBACK_API_KEY` 与 `FALLBACK_MODEL` 都要填才会生效；URL 可留空（沿用主 URL） |

| 按钮 | 作用 |
|---|---|
| 🔌 测试连接 | 用当前配置发一条极短请求（约 4 token），返回模型名与样例输出；失败会在状态条显示原因 |
| 💾 保存 | 写回 `.env`（只改这 6 个键，其余行原样保留），**立即生效，无需重启** |
| 取消 | 关闭弹窗 |

> **厂商选择建议**：主备两家**必须是不同厂商**。同一家同一账号，限流或宕机时会一起挂，备用就白配了。

### 2.5 ✨ AI 建书向导（三步）

| 步 | 你做什么 | AI / 系统做什么 | 产物 |
|---|---|---|---|
| **1. 聊** | 在左边输入框说出你的故事想法（题材、想写什么、卡在哪），`Ctrl+Enter` 发送；可多轮 | AI 以编辑身份追问、帮你理清 | 对话记录 |

## 三、常见问题 FAQ

| # | 问题 | 症状 | 怎么办 |
|---|---|---|---|
| 1 | **Key 没配 / 配了还是提示未配置** | 状态条「⚠ 未配 Key」，或 CLI 打印「缺少 API key」 | ① 确认项目根有 `.env`（不是 `.env.example`）；② 打开 `.env` 确认 `AGNES_API_KEY=` 后面有内容且长度 > 10（就绪判定就看这个）；③ Web 设置页重填一次并保存；④ 点「🔌 测试连接」看真实连通性；⑤ CLI 可用 `--key sk-xxx` 临时指定 |
| 2 | **写章失败** | 终端 `⚠ 主模型 …请求异常` / `模型调用失败（重试 2 次后放弃）`；Web 弹「写章失败：…」 | ① 先看 `finish_reason`（`[用量] … \| finish=`）：`length` = 输出被截断（降输入或换模型），`stop` 但空内容 = 模型抽风（重跑即可）；② 检查 Key 是否欠费；③ 检查 Base URL 是否带 `/v1/`；④ 配好 `FALLBACK_*` 让它自动切备用；⑤ 仍失败看 Web 返回的 `log` 字段（引擎 stdout+stderr 尾部 2000 字符） |
| 3 | **端口占用** | 启动时报 `Address already in use`，或页面打不开但黑窗口正常 | ① Windows：`netstat -ano \| findstr :8801` 找到 PID → `taskkill /PID <PID> /F`；② macOS/Linux：`lsof -i :8801` → `kill -9 <PID>`；③ 或换个端口：`python web/server.py --port 8802`；④ 注意排查的是 **8801**（不是 bat 提示里的 8899） |
| 4 | **中文乱码** | 终端报 `UnicodeEncodeError: 'gbk' codec can't encode` | Windows 先 `set PYTHONUTF8=1` 再跑；或改用 PowerShell / Windows Terminal；`start-web.bat` 已 `chcp 65001`，走 Web 不受影响 |
| 5 | **账本怎么手改** | 想直接指定下一章接哪、想修正记错的事实 | ① CLI/编辑器打开 `books/<书名>/story_state.md`；② 或 Web 里打开「📒 记忆账本」直接改，`Ctrl+S` 保存；③ **只能改小节内部条目，不要改/删 7 个 `## ` 标题**；④ 改完它就是续写的最高优先级依据 |
| 6 | **误改了怎么回滚** | 正文被 apply 改坏了 / 手改错了 | ① **apply 造成**：把 `chXXX.bak.md` 复制回 `chXXX.md`（注意：备份是**首次 apply 前**的原稿，不含之后的手改）；② **手改造成**：编辑器 `Ctrl+Z` 若在保存后失效，就只能靠 `books/` 的定期备份；③ **账本改坏**：`--init-state` 重建（会丢历史，先备份当前账本）；或 `--state-only --chapter N` 让模型基于该章正文重算 |
| 7 | **章节列表里少了几章 / 顺序怪** | ch010 排在 ch002 前面，或某章不显示 | 文件名必须严格是 `ch` + **3 位数字** + `.md`（`ch001.md` ✅、`ch1.md` ❌、`ch001.meta.md` 仅被 `chapter_no_of()` 识别但不算正文）。改名为 3 位数字即可 |
| 8 | **Web 按钮点了报 404 `no route`** | 写章/体检/去味/应用/建书点了没反应 | ✅ **已修复**（2026-09-03）：路由已移回 `handle_api_post`，`web/test_routes.py` 16 断言守护。若再遇 404：先确认服务重启到了最新代码 |
| 9 | **设置面板长得不对 / 建书向导书名没回填** | 输入框没有密码掩码、样式异常、提取书名后书名框仍为空 | 🟡 **大部分已修复**（2026-09-03）：模板字符串破损与 `$const` 已修；但章节页动作条仍有 P0 bug（`chapterActions()` 未定义，v0.2 首件修复）。设置页异常时的临时办法：手改 `.env` |
| 10 | **同一个动作点了两次 / 两个窗口同时操作** | 正文或账本内容错乱 | 本项目**没有文件锁**。同一本书同一时刻只跑一个动作；Web 遮罩只在当前页面生效，多开标签页无效 |
| 11 | **跑测试有什么用** | — | `python scripts/smoke_test.py`：零网络零依赖，**27 条断言**（模块加载、句子切分与引号边界、L1 命中、apply 备份/替换/跳过、上下文配方组装、双引擎 failover、账本 7 小节结构校验）；另有 `python web/test_routes.py`（Web 路由 16 条断言）。**改完任何代码先跑它**，失败会以退出码 1 结束 |
| 12 | **AI 腔指数多少算好** | — | 指数 = `(hard×2 + soft项 + 标点超标) × 1000 / 字数`。本项目未设官方阈值，实践口径：**< 1.0 优秀，1.0–3.0 可接受，> 3.0 建议 polish 一遍**。更重要的是看 hard 命中是否为 0 |
| 13 | **账本看着不对（缺小节）** | 打开账本发现没有「伏笔账本」等 | ✅ **双重保险已就位**（2026-09-04 更新）：示例书账本已恢复完整；且写章流程已加 `validate_state()` 自动校验，截断会被当场拦截。手工处置仍见 FAQ 6 第 ③ 条 |

## 四、数据备份与恢复

### 4.1 什么在什么不在版本控制里

| 数据 | 位置 | 是否入 git | 丢了怎么办 |
|---|---|---|---|
| 三件套（设定/角色卡/大纲） | `books/<书名>/*.md` | ✅ 入库 | `git` 可恢复 |
| **记忆账本** | `books/<书名>/story_state.md` | ✅ 入库 | `git` 可恢复 |
| **章节正文** | `books/<书名>/chapters/chXXX.md` | ❌ **不入库** | 只能靠文件备份 |
| 体检/审计报告、diff JSON | `chapters/` 下 | ❌ 不入库 | 可重跑生成（花 token） |
| 应用前原稿 | `chXXX.bak.md` | ❌ 不入库 | — |
| 配置 `.env` | 项目根 | ❌ 不入库 | 用 `.env.example` 重建（Key 要重新填） |

> **最危险的一句话**：`chapters/` 被 `.gitignore` 排除，这是为了保护隐私与仓库体积，代价是**正文没有任何版本控制**。

### 4.2 备份方案（三档，按推荐度）

| 档 | 做法 | 频率 | 覆盖 | 成本 |
|---|---|---|---|---|
| 🥇 **整目录复制**（推荐） | 把整个 `novel-ledger/`（或至少 `books/`）压缩成 `novel-ledger-YYYYMMDD.zip` 放到外部硬盘/网盘 | **每写完一章一次**；至少每周一次 | 全部（含 `.env`、正文、账本） | 几十 MB，几秒 |
| 🥈 **定稿归档** | 确认定稿的章节复制到 `books/<书名>/versions/`（该路径已被 ignore，不会误提交） | 每章定稿时 | 正文 | 低 |
| 🥉 **git 提交** | `git add books/<书名>/*.md && git commit -m "更新账本/设定"` | 账本或设定有变更时 | 三件套 + 账本（**不含正文**） | 无 |

### 4.3 恢复对照表

| 丢了什么 | 从哪恢复 | 命令/操作 |
|---|---|---|
| 单章正文（apply 改坏） | `chXXX.bak.md` | 复制覆盖 `chXXX.md`（注意是首版备份） |
| 单章正文（彻底没了） | 最近的整目录备份 | 从 zip 里取 `books/<书名>/chapters/chXXX.md` |
| 账本 | git | `git checkout -- books/<书名>/story_state.md` |
| 账本（无 git / 已截断） | ① 手补缺失小节 ② 重算 ③ 重建 | ② `python scripts/write_chapter.py --book books/<书名> --state-only --chapter N`；③ `--init-state`（**会丢历史，先备份**） |
| 三件套 | git 或 `sample_book/` | `git checkout --` 或重新复制模板 |
| 体检/审计报告 | 重跑 | `deai.py --polish …` / `write_chapter.py --audit …`（花 token） |
| `.env` | `.env.example` | `copy .env.example .env`（Windows）/ `cp`（macOS/Linux），再填 Key |
| 整个项目 | 整目录备份 + git 远端 | 解压 + `git clone` |

### 4.4 备份检查清单（建议贴在桌面）

- [ ] 写完一章 → 看一眼账本 7 小节是否齐全（防截断）
- [ ] 写完一章 → `chapters/` 里新文件在不在
- [ ] 每天收工 → 打一个 `books/` 的 zip 到外部存储
- [ ] 每周 → 确认一次备份能正常解压打开
- [ ] 换电脑/重装前 → 确认 `books/` 整个目录已复制出去（**它不在 git 里**）
