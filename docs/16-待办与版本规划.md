## 二、后续版本规划

| 版本 | 目标 | 大致时间安排 |
|---|---|---|
| **v0.2.1（当前，进行中）** | "日常好用"打磨：实时直播 / AI 助手 / 导入导出 / 界面反馈八连改+二批优化 | 本周内收尾：剩余验收 1 天 + 修补 0.5 天 |
| **v0.2.2（收尾补丁）** | E2E 五流程重跑全绿 → 快照缺口补算 → /legacy 归档 → 正式发布 v0.2.1/v0.2.2 标签 | 1 天 |
| **真实使用期（重要）** | 老大自开新书连写 30 章+，攒"不顺手清单"，据此定 v0.3 优先级 | 1-2 周（与 v0.3 开发并行） |
| **v0.3（功能扩展，按需挑选 2-4 项）** | 见下方待实现列表 P1 项：拆书续写 / 学自己文风 / 账本重算 / 大纲评估扩写 优先 | 1-2 周/项 |
| **v0.4（远期）** | 模拟读者评分 / 去味对比分 / 界面卡片化 / 风格包切换 | 视项目热度 |
| **明确不做** | 富文本编辑器、多用户/云端、漫画短剧衍生、Node 构建链强依赖 | ——会破坏"零依赖、单机、数据不出本机"三大卖点 |
