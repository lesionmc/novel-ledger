# deconstruct.md — 拆书 7 维规则

> 用途：把一本对标作品拆成可复用的写作资产时，按以下 7 维逐项过检。
> 每维给 2-3 条可执行检查点；产出物写入书的 `_research/` 拆书报告。

## 1. 文风指纹
- [ ] 摘录 3 段各 300 字，统计：平均句长、对话/叙述比例、最常用动词Top10。
- [ ] 找出 3 个"只属于这本书"的表达习惯（如方言、行业黑话、固定比喻）。

## 2. 情节结构
- [ ] 按幕/卷画出主事件链：每个转折点前后主角目标与阻碍各是什么。
- [ ] 标出支线并入主线的时间点，判断是否有废弃支线。

## 3. 人物塑造
- [ ] 对每个主要角色记录：出场方式、口头禅、第一次"违背人设"的行为发生在哪章、代价是什么。
- [ ] 检查配角是否工具人：有没有独立目标与拒绝主角的时刻。

## 4. 独特性
- [ ] 用一句话说清"这本删掉主角名后还剩什么"（世界观/设定/文风至少占一项）。
- [ ] 找出 2 个同类题材作品没有的元素；找不到则该书不可作为差异化对标。

## 5. 情绪曲线
- [ ] 每章末标注读者情绪值（-2 沉痛 ~ +2 爽点），连成曲线看节奏。
- [ ] 检查连续 3 章同号（持续憋屈/持续爽）是否配有补偿机制。

## 6. 热梗与时代感
- [ ] 列出所有依赖当下热梗/社会事件的段落，标出"几年后会失效"的等级。
- [ ] 判断这些梗是融入人物还是作者跳出来讲段子。

## 7. 章节钩子设计
- [ ] 每章末钩子归档为四类：悬念/危机/反转/期待，统计占比。
- [ ] 连续 5 章同类钩子即为疲劳信号，记录并避开。
