# graph.md — 关系图谱防幻觉规则（R38）

> 关系图谱 = `books/<书>/关系图谱.json` + `.md`，由 `scripts/relation_graph.py --book books/X` 产出。

## 防幻觉铁律（代码已强制，人工复核时同样遵守）

1. **短语必须有原文证据**：每条关系短语必须能回溯到引用章节里的原句。
   L2 产出的 evidence 会逐条回验——不是所指章节正文的精确子串就直接丢弃，绝不入图。
2. **证据必须带章节号**：证据句只允许从「角色对同段共现」的段落里取，天然带出处；
   没有章节号的关系在回验阶段一律作废。
3. **泛称不入图**：他/她/那人/此人/对方等泛称一律不建节点（`GENERIC_NAMES` 黑名单），
   防止代词把图谱污染成以泛称为中心的星型垃圾图。
4. **L2 输入设预算**：喂给模型的证据池超过 3000 token（1 汉字≈1 token 保守口径）即截断，
   保共现次数最高的角色对——防 agnes 推理失控吞光返回空。
5. **图谱是证据的索引，不是事实的来源**：续写时图谱用来「想起某两人该同框」；
   人物关系的最终事实以账本（story_state.md）与正文为准，图谱与账本冲突时账本优先。

## 更新节奏

- 每 5-10 章重跑一次（共现统计零 token；配置了 API key 才会生成关系短语）。
- 新角色记得先补进 `角色卡.md`——图谱节点来自角色卡，卡里没有的人不会被统计。
